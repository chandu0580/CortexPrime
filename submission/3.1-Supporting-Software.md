# 3.1 — Supporting Software

**Project:** CortexPrime — AI-Native Enterprise Operations Intelligence Platform
**Reg. No:** 24BMMCA023  **Name:** Chandu S

---

## A. Mandatory — the project will not run without these

| # | Software | Version | Purpose | Where to get it |
|---|---|---|---|---|
| 1 | **Python** | 3.13 or later | Backend runtime (FastAPI) | python.org/downloads |
| 2 | **Node.js** | 20 LTS or later | Frontend runtime (Next.js 16) | nodejs.org |
| 3 | **npm** | 10+ (ships with Node) | Frontend package manager | bundled with Node.js |
| 4 | **PostgreSQL** | 16, with **pgvector** extension | Primary database + vector storage | postgresql.org / Docker image `pgvector/pgvector:pg16` |
| 5 | **Git** | 2.40+ | Source control, repository connectors | git-scm.com |

> **Note on PostgreSQL:** a plain PostgreSQL 16 install is *not* sufficient — the
> `pgvector` extension is required for semantic memory. The simplest route is the
> Docker image listed above, which bundles it.

## B. Strongly recommended — required for full functionality

| # | Software | Version | Purpose |
|---|---|---|---|
| 6 | **Docker Desktop** | 24+ | Runs all backing services with one command; also the target of the container-health detector |

| 8 | **Redis** | 7.2 | Caching, session store, real-time pub/sub |
